## Veilr v1.0.2 — 配布の仕組みの変更

機能の変更はありません。

### 変更

- 配布する exe を、GitHub Actions が公開しているソースからビルドするようにしました（手元でビルドしたものは載せません）
- `SHA256SUMS.txt` と、ビルドの証明（attestation）を付けました。確かめ方は README の「安全性」にあります

```powershell
Get-FileHash .\Veilr.exe -Algorithm SHA256
gh attestation verify .\Veilr.exe -R laxshmate/Veilr
```

### ダウンロード

`Veilr.exe` をダウンロードして実行してください。.NETランタイム不要（self-contained）。

> **SmartScreenの警告が出る場合**
> 初回起動時に「WindowsによってPCが保護されました」と表示されることがあります。
> 「詳細情報」→「実行」で起動できます。

### 動作環境

- Windows 10 / 11
- GPU高速化: DirectX 11対応GPU（Feature Level 11_0以上）
