## Veilr v1.0.6 — 設定ファイルの名前を変更

### 変更

- 設定ファイルの名前を `settings.json` から **`Veilr_settings.json`** に変えました。どのアプリの設定か分かりやすくなります
  - 前の版の `settings.json` は読み込みません。設定は既定に戻ります（前の設定を使いたいときは、ファイル名を `Veilr_settings.json` に変えてください）。不要なら消してください
- 開発用の動作記録 `capture-profile.log` を作らないようにしました。前の版が作ったものは消して構いません

### ダウンロードした exe を確かめる

```powershell
Get-FileHash .\Veilr.exe -Algorithm SHA256
gh attestation verify .\Veilr.exe -R laxshmate/Veilr
```

SHA-256 がリリースの `SHA256SUMS.txt` と同じなら、改ざんされていません。

### ダウンロード

`Veilr.exe` をダウンロードして実行してください。.NETランタイム不要（self-contained）。

> **SmartScreenの警告が出る場合**
> 初回起動時に「WindowsによってPCが保護されました」と表示されることがあります。
> 「詳細情報」→「実行」で起動できます。

### 動作環境

- Windows 10 / 11
- GPU高速化: DirectX 11対応GPU（Feature Level 11_0以上）
