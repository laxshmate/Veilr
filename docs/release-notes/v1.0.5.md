## Veilr v1.0.5 — exe のファイル情報を整理

### 変更

- exe のプロパティ（詳細）に、著作権「Copyright © 2026 laxshmate」とファイルの説明を表示するようにしました
- 製品バージョンを「1.0.5」のように番号だけで表示するようにしました

### ダウンロードした exe を確かめる

```powershell
Get-FileHash .\Veilr.exe -Algorithm SHA256
gh attestation verify .\Veilr.exe -R laxshmate/Veilr
```

SHA-256 がリリースの `SHA256SUMS.txt` と同じなら、改ざんされていません。

### ダウンロード

`Veilr.exe` をダウンロードして実行してください。.NETランタイム不要（self-contained）。

> **SmartScreenの警告が出る場合**
> 初回起動時に「WindowsによってPCが保護されました」と表示されることがあります。
> 「詳細情報」→「実行」で起動できます。

### 動作環境

- Windows 10 / 11
- GPU高速化: DirectX 11対応GPU（Feature Level 11_0以上）
